## How to use this (read once)

Every image below is TWO steps, nothing else:

1. **Attach** the files listed under it (drag them into the Gemini message).
2. **Paste** its grey block as one message. The block contains everything — style, rules, subject.

Then:
- **Save with right-click → "Save image as…"** into `C:\Users\AllanBrinkVraa\Downloads\art-boat`.
  Never the download button on the image (it stamps a ✦ watermark). Filenames don't matter.
- **Stay in the same chat for all images of one section** (A, B, C…) so the style carries; start a new
  chat for the next section.
- **Check the count before you save the fish boxes** — exactly 5 + 5. If not, say "Try again —
  exactly five fish in each row, ten in total" in the same chat. Extra takes are fine; I pick the best.
- When you're done, tell me. I validate every image **before** anything is moved or wired, and show
  you a contact sheet.

The single fish is NOT generated — the app already has it (`fish.webp`), and every fish in these
images must be that same fish. That is why it is attached so often.

## For the build session (not for pasting)

- First try (2026-10-14): a "4 separate images" message returned one 2×2 collage with white gutters,
  and the boxes held 2×4 = 8 fish. Hence one image per message and row-by-row counts. If a collage
  still arrives, it can be split into quadrants — but the white gutters must be cropped off before
  keying, and each quadrant is only ~420px.
- Validation before anything is moved: identify each subject from a contact sheet; reject collages,
  text, a painted sky/sea behind a green-screen subject (green fraction ~75–95% is good), any box that
  does not hold exactly ten fish, fish that differ from `fish.webp`, ✦ watermarks.
- Keying: `scripts/optimize-theme-art.mjs` (green-excess). The teal waves (D) sit near the screen hue —
  measure green-excess before keying. No green hulls were asked for on purpose.
- The backdrop (E) is opaque: resize + WebP, no keying.
- Sounds are not Gemini: fish lands / box lands done (Kenney CC0); still to source — horn, bow splash,
  packing, boat arrive, harbour ambience loop (`art-src/sfx/SOURCES.md`).
