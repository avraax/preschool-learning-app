  then **paste** the grey block.
- **Save with right-click → "Save image as…"** into `C:\Users\AllanBrinkVraa\Downloads\art-boat`.
  Never the download button on the image (it stamps a ✦ watermark). Filenames don't matter.
- **If Gemini still returns ONE picture with four images inside it**, save it anyway — I can cut it
  into four. But first try once in the same chat: *"Please send them as 4 separate images, not one
  picture."*
- **Count the fish in every box before saving: exactly 5 + 5.** If not, say in the same chat:
  *"Try again — exactly five fish in each row, ten in total."*
- Extra takes are welcome; I pick the best. When you're done, tell me — I validate every image
  **before** anything is moved or wired, and show you a contact sheet.

The single fish is NOT generated — the app already has it, and every fish in these images must be that
same fish. That is why it is attached so often.
