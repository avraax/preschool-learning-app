Status: ready to paste (rewritten 2026-10-14 so every batch is self-contained). Owner generates; the
build session validates, keys, trims and wires. Bar (owner): this game is the app's quality benchmark —
re-roll anything that isn't clearly good.

## How to use this (read once)

Each batch below is TWO steps, nothing else:

1. **Attach** the files listed under "Attach" (drag them into the Gemini message).
2. **Paste** the grey block — the whole block, as one message. It contains everything Gemini needs.

Then:
- **Save each image with right-click → "Save image as…"** into `C:\Users\AllanBrinkVraa\Downloads\art-boat`.
  Never the download button on the image (it stamps a ✦ watermark and can add stray elements).
  Filenames don't matter.
- **One new chat per batch.** If a batch comes back as one collage instead of 4 images, write
  "Please give me 4 separate images, not a collage" in the same chat.
- **Re-roll freely.** Saving extra takes is fine — I pick the best of each subject when validating.
- When you're done, tell me. I check every image **before** anything is moved or wired (style match,
  clean green background, ten fish really ten, no text, nothing scary) and show you a contact sheet.

Why the attachments matter: they make Gemini match the app's existing clay style. The single fish is
NOT generated at all — the app already has it (`src/assets/games/math/fish.webp`), and every fish in
these images must be that same fish.

## For the build session (not for pasting)

- Validation before anything is moved: identify each subject from a contact sheet; reject collages,
  text, a painted sky/sea behind a green-screen subject (measure the green fraction — ~75–95% is good),
  a box that does not hold exactly ten fish, fish that differ from `fish.webp`, ✦ watermarks.
- Keying: `scripts/optimize-theme-art.mjs` (green-excess). The teal waves (batch 4) sit near the screen
  hue — measure green-excess before keying. No green hulls were asked for on purpose.
- The backdrop (batch 5) is opaque: resize + WebP, no keying.
- Sounds are not Gemini: fish lands / box lands are done (Kenney CC0); still to source — horn, bow
  splash, packing, boat arrive, harbour ambience loop (`art-src/sfx/SOURCES.md`).
